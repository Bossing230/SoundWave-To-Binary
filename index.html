Explain It

  1. How does your app change a sound wave into binary? Name the three steps.
    My app samples the wave by measuring its height at evenly spaced times across one full period, quantizes each height by rounding it to the nearest whole level (0 to 2bits−1), and encodes each level as a binary number padded with leading zeros.
  2. Run Test A again with 2 bits, then 6 bits. Which gives more detail about the wave, and why?
    6 bits gives more detail because it allows 64 levels instead of only 4, so each rounded sample stays much closer to the true wave height and the binary recording preserves more of the original shape.
  3. Which test has the longest wavelength? How is wavelength connected to frequency?
    Test B (200 Hz) has the longest wavelength, 171.5 cm. Wavelength equals 343 ÷ frequency, so wavelength and frequency are inversely related: the lower the frequency, the longer the wavelength.
  4. What was the hardest stage to build, and how did you fix it?
    The hardest stage was Stage 4 (binary), especially padding each level with leading zeros so every value has exactly "bits" digits I fixed it by converting the level to base 2 and then adding zeros in front until the string reached the right length.
